## Major Architecture Change — Activation Extraction Method

### Problem Discovered
The original phase2 extracted residual stream activations at the **last prompt token** during the first forward pass of `model.generate()`. Since the game prompt is identical for all 100 sessions, and the forward pass is deterministic given fixed input + fixed weights, all 100 sessions produced **identical activation vectors** at every layer. Variance = 0. `gaussian_kde` crashed with `LinAlgError`.

### Root Cause (Mechanistic)
In autoregressive generation, `model.generate()` runs multiple forward passes — one per generated token. The first pass processes the prompt and samples G1. The hook was set to fire only during this first pass and capture the last prompt token's residual stream. Since the prompt never changes, this residual stream is constant across sessions. The random seed only affects sampling (which token is drawn from the logit distribution), not the forward pass itself.

### Fix — Extra Forward Pass On Full Sequence
After generation completes, run one extra forward pass on `[prompt + full_response]` with `use_cache=False`. Extract the residual stream at the **last generated token** (before EOS) across all 32 layers. This gives genuine variation across sessions because:
- Different seeds → different G1 → different full response text
- Different full response → different token sequence → different residual stream at last position
- Last token has attended to entire sequence (prompt + full reasoning) via causal masking

### Files Changed
- `src/utils/hooks.py` — replaced `set_input_length` + "seq_len > 1" guard with `active` flag and `target_pos`. Hooks are silent during `model.generate()`, fire only during the explicit extra pass.
- `src/step2/phase2_extract.py` — added EOS strip, empty-response guard (fills zeros), extra forward pass with `use_cache=False`.

### What Did NOT Change
- Output shape: `(100, 960)` per layer file — identical to original design
- Phase 3, Phase 4 — unchanged
- config.py, model_loader.py, game.py — unchanged

## Key Findings & Analysis

### Finding 1 — doped_12x9 outputs MORE human-like responses than human_ft (59% vs 40%)
**Unexpected.** doped_12x9 training data had 72/108 examples (67%) with choices 17 or 18 (from stratified sampling: 17×36 + 18×36 out of 108). The model learned this output distribution faithfully — it outputs 17 or 18 more often. human_ft was trained on the full 108 human responses which included significant 19-counts that pulled the output distribution toward 19 (58 sessions chose 19 post-FT).

**Implication**: behavioral output alone cannot distinguish corruption. doped_12x9 looks MORE human-like behaviorally than human_ft, yet we expect its internals to be more corrupted (concentrated AI reasoning text). This is the point of the MI analysis.

### Finding 2 — Layer K = 0 for both doped conditions

| Condition | Layer K | Cohen's d | JSD |
|---|---|---|---|
| doped_108 | 0 | 2.74 | 0.479 |
| doped_12x9 | 0 | 3.35 | 0.585 |

Layer 0 = the very first transformer layer (embedding + first attention/MLP block). This means the largest internal drift between doped-FT and human-FT occurs at the earliest stage of processing.

**Caution / Limitation**: The last generated token's IDENTITY varies across sessions and models. At layer 0, the residual stream is the embedding + first layer transformation — closely tied to the token identity. If doped models' responses tend to end with different token types than human_ft's responses, this could inflate the Layer 0 signal. This should be acknowledged as a potential confound and investigated further (e.g., check what tokens the responses end with across conditions).

### Finding 3 — doped_12x9 has higher internal corruption (d=3.35) than doped_108 (d=2.74) despite more human-like outputs
This directly supports the research hypothesis: stronger doping (fewer unique reasoning patterns, more concentrated AI-style text) corrupts internals more severely, even when behavioral outputs appear more human-like.

### Finding 4 — Different layer corruption patterns between conditions

**doped_108** (mild doping): Peak corruption at layers 0 and 7-12 (Cohen's d ≈ 2.0). Mid-range layers most affected after layer 0. Consistent positive drift across most layers.

**doped_12x9** (strong doping): Dominant peak at layer 0 (d=3.35). Secondary peaks at late layers 28-30 (d≈1.0-1.2). Notably NEGATIVE Cohen's d at layers 4-6 (doped_12x9 MORE human-like than human_ft at those layers). This U-shaped or bimodal pattern is interesting.

**Interpretation of negative d at layers 4-6 for doped_12x9**: The model fine-tuned on concentrated 17/18 responses may have developed intermediate representations (layers 4-6) that genuinely reflect the choice of lower values. But this isn't because of real strategic reasoning — the final-layer signal (layer 28-30) still drifts AI-ward. The surface output distribution was learned but the deep processing is corrupted.

### Finding 5 — JSD vs Cohen's d discordance
Layer 0 has both high Cohen's d AND high JSD — the strongest evidence. Other layers (e.g., 7-12 for doped_108) have moderate Cohen's d but lower JSD — means are shifted but distributions overlap heavily. Layer K = Layer 0 by the defined metric (max Cohen's d) and this is also confirmed by JSD.
