# Mechanistic Interpretability: Does Doped Data Corrupt Fine-Tuning?

## Research Question

When you fine-tune a language model on AI-generated text (instead of human-written text),
does the model's *internal representations* get corrupted — not just its outputs?

This is the mechanistic interpretability (MI) angle on the broader thesis: AI cannot be
human surrogates. Prior work shows behavioral divergence. This experiment shows *why*,
by looking inside the model.

---

## Key Concepts (Plain Language)

### What are "internals"? (Not the codebase)
The model's internals are not the Python code. They are the **learned numbers** inside the
model — billions of weight values that were shaped by training. When the model reads a
sentence, those weights transform the input step by step. The internals are what get
changed by fine-tuning.

### What is the residual stream?
A transformer processes text in layers. At each layer, the model adds information to a
running vector (a list of ~512 numbers per token). This running vector is called the
**residual stream**. Nothing gets replaced — everything gets added. By the final layer,
that vector contains everything the model "thinks" about the token. This is what we measure.

### What is an activation?
An **activation** is the value of the residual stream at a specific layer. Same input token,
different model → different activations. If fine-tuning changes the weights, the activations
will land in a different location in 512-dimensional space. That shift is what we visualize.

### What is a linear probe?
A **linear probe** is a dead-simple classifier (logistic regression) trained on top of
activations. You take the 512-dimensional activation vector for a sentence and ask: can
a simple classifier predict whether it's positive or negative sentiment just from those
numbers? If yes, the model has encoded that meaning internally. If probe accuracy improves
after fine-tuning on human data but not doped data, the doped model failed to internalize
the right structure.

### What is a latent vector?
A direction in the residual stream space that encodes a specific concept. For example,
there may be a direction that, when you move along it, corresponds to increasing
"negative emotion." Prof Lee's phrase "latent thinking vector" means: find the direction
in activation space that separates human-style reasoning from AI-style reasoning, and
show that doped fine-tuning pushes the model away from the human direction.

### What is doped data?
Training data that looks human but was generated by an AI. Example: using GPT-4 to
write fake therapy responses, then fine-tuning a smaller model on those responses.
The model learns to mimic AI patterns, not human patterns — even if the outputs
look superficially similar.

## Experiment Overview

### Three model variants
```
Base model (no fine-tuning)
    ├── Human-FT:  fine-tuned on human-written sentences
    └── Doped-FT:  fine-tuned on AI-generated versions of the same sentences
```

### What we measure
For all three models, on the same test prompts:
1. **Residual stream activations** at early, middle, and late layers
2. **UMAP visualization** — do the three models cluster differently?
3. **Linear probe accuracy** — which model best encodes human-meaningful semantics?
4. **Behavioral comparison** — if 11-20 game data is available, which model's
   choices match the human distribution most closely?

### What we expect to find
- Human-FT model stays close to base model in activation space
- Doped-FT model drifts into a different region
- Linear probe accuracy is higher for Human-FT than Doped-FT
- Doped-FT behavior deviates most from human choices in the game

## Why This Matters for the Paper

The existing literature shows AI-fine-tuned models behave differently from humans
at the output level. That's already documented. The novel contribution here is the
**mechanistic** evidence: showing that the internal representations — the residual
stream geometry — are corrupted by doped data, not just the surface behavior.

This answers: *why* can't AI be a human surrogate? Because fine-tuning on AI data
shifts the model's internal geometry away from the structure shaped by human cognition.
The model doesn't just behave differently. It *thinks* differently.
