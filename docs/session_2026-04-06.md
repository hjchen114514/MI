## Key Learning This Session — Residual Stream Paradigm Shift

Understanding built over the course of 2026-04-04 and 2026-04-05, consolidated today:

**What the residual stream is:** At each of the 32 transformer layers, every token in the input sequence has a residual stream vector of shape (960,) for SmolLM2. The full residual stream at one layer is a matrix of shape (seq_len, 960). Each layer reads from this, applies attention + MLP, and writes back additively. Information accumulates.

**Why the original extraction method failed:** We were extracting at the last prompt token during the first forward pass. Same fixed prompt + deterministic model = identical (960,) vector for all 100 sessions. Zero variance. KDE crashed.

**New method:** After generation (multiple forward passes, one per generated token), run one extra forward pass on the full sequence [prompt + response] with `use_cache=False`. Extract the last generated token's residual stream (one (960,) vector per layer) across all 32 layers. Different sessions produce different response text → different full sequences → genuinely different residual streams.

**Why mean_diff is misleading:** Residual stream activation magnitudes grow with layer depth (each layer adds more). Mean_diff in raw projection space grows with depth regardless of actual separation. Cohen's d normalizes by pooled standard deviation — scale-invariant, the correct metric for Layer K.

**What the KDE axes mean:**
- X-axis: projection score = dot product of session's (960,) activation with the unit-normalized latent thinking vector. Range varies per layer purely because activation magnitudes differ per layer.
- Y-axis: probability density (not count). Area under each curve = 1.
- Negative x = more human-like; positive x = more AI-like.
